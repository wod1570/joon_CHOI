What I Built

이 툴 조합으로 만든 것은 단순 스크립트가 아니라 실무용 운영 시스템입니다

이 프로젝트는 단순 스크립트가 아닌, 실제 사내 마케팅 업무에 적용된 자동화 운영 시스템입니다. Python, Selenium, GPT, Claude, Gemini를 개별적으로 사용하는 수준을 넘어서, 검색 → 콘텐츠 생성 → 실행 → 결과 관리까지 하나의 프로세스로 통합했습니다.

  • 업무 흐름에 맞게 시스템 구조를 직접 설계하고 구현
  • 비개발자도 사용할 수 있도록 GUI와 로그/결과 관리 기능을 함께 제공
  • AI를 개발 보조와 기능 구현 양쪽에 활용해 개발 속도와 결과 완성도를 동시에 끌어올림

  • Selenium 기반으로 동적 검색 결과의 실제 노출 여부와 순위를 확인
  • 대량 키워드 처리와 결과 저장 흐름을 자동화해 반복 점검 시간을 줄임
  • 운영자가 수작업으로 체크하던 프로세스를 재현 가능한 점검 도구로 전환

  • AI-Driven Content: 단순 작업을 넘어 LLM을 활용한 콘텐츠 지능화 및 예외 처리 구현
